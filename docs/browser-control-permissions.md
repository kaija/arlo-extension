# Chrome MV3：可操控瀏覽器的擴充功能權限

本筆記只依據 Chrome 官方擴充功能文件。這裡的「操控」分成：操作網頁 DOM、整理分頁／視窗，以及改變網路或瀏覽器資料。**取得網站存取權不代表 Chrome 會替產品確認送出訂單、刪除資料等頁面內動作；那些仍要由產品自行設計確認機制。**

## 先記住：API 權限與網站範圍是兩件事

- `permissions`：開啟特定 Chrome API；有些會顯示安裝警告。
- `host_permissions`：持續存取指定比對模式的網站；常是讀取／改寫網頁所缺的另一半。
- `optional_permissions`／`optional_host_permissions`：先在 manifest 宣告，再從按鈕點擊等使用者手勢呼叫 `chrome.permissions.request()` 申請；適合把網站存取延後到真正需要時。
- `content_scripts.matches` 也會宣告可注入的網站範圍；它不是 API 權限，卻同樣代表可在匹配網站執行程式。

[官方：Declare permissions](https://developer.chrome.com/docs/extensions/develop/concepts/declare-permissions)｜[官方：Permissions API](https://developer.chrome.com/docs/extensions/reference/api/permissions)

## 一般網頁代理最需要的能力

| ------------------------------------ | ------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 只在使用者點選後操作目前分頁         | `"activeTab"` + `"scripting"`                                                        | 在目前 active tab 注入 JS／CSS；可暫時取得該分頁 URL、標題、favicon。授權在導覽到不同來源或關閉分頁後失效。 | 範圍最小，且 `activeTab` 不顯示安裝警告；仍能讀／改當下網站內容。適合一次性的「幫我操作這個頁面」。[官方：activeTab](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)｜[官方：scripting](https://developer.chrome.com/docs/extensions/reference/api/scripting) |
| 持續操作指定網站                     | `"scripting"` + `host_permissions`，或在使用者同意後取得 `optional_host_permissions` | 對匹配網站以 `executeScript()`、`insertCSS()` 等方式操作 DOM。                                              | 網站內容、表單與帳號狀態可能受影響；不要預設 `&lt;all_urls&gt;`，優先逐站、可撤回地申請。[官方：scripting](https://developer.chrome.com/docs/extensions/reference/api/scripting)                                                                                                       |
| 自動在指定網站載入內容腳本           | `content_scripts.matches`                                                            | 依 manifest 比對模式自動注入內容腳本。                                                                      | 不必等使用者當下點擊，故風險比 `activeTab` 高；只列出實際需要的網域。[官方：Declare permissions](https://developer.chrome.com/docs/extensions/develop/concepts/declare-permissions)                                                                                                    |
| 建立、導覽、重新載入、移動、關閉分頁 | `chrome.tabs`；多數動作**不需** `"tabs"`                                             | 建立分頁、導覽網址、重新載入、排列分頁、靜音等。                                                            | `"tabs"` 不是取得 Tabs API 的開關；它是讀取所有分頁敏感欄位（URL、標題、favicon、pending URL）的權限，會帶來瀏覽紀錄風險。只有需要跨網站讀這些欄位才申請。[官方：tabs](https://developer.chrome.com/docs/extensions/reference/api/tabs)                                                |
| 建立與重排視窗                       | `chrome.windows`；沒有獨立的 `"windows"` manifest 權限                               | 建立、修改、重排瀏覽器視窗。若要讀視窗內分頁的敏感欄位才需 `"tabs"`。                                       | 視窗／焦點突然變動會打斷使用者；把範圍明確限制在目前工作視窗。[官方：windows](https://developer.chrome.com/docs/extensions/reference/api/windows)                                                                                                                                      |
| 管理分頁群組                         | `"tabGroups"`                                                                        | 改群組標題、顏色、折疊狀態與位置。                                                                          | Chrome 的警告是「檢視及管理分頁群組」；只在產品確實提供分頁整理時加入。[官方：tabGroups](https://developer.chrome.com/docs/extensions/reference/api/tabGroups)                                                                                                                         |
| 顯示側邊欄                           | `"sidePanel"`                                                                        | 在 Chrome 側邊欄呈現擴充功能 UI。                                                                           | 這只提供 UI 容器，**不**給網站讀寫權；網頁操作仍須上述網站權限。[官方：sidePanel](https://developer.chrome.com/docs/extensions/reference/api/sidePanel)                                                                                                                                |
| 擷取目前可見畫面                     | `activeTab` 或 `&lt;all_urls&gt;`                                                    | `tabs.captureVisibleTab()` 可擷取可見區域；`activeTab` 也可用於一些通常受限制的敏感頁面截圖。               | 螢幕截圖可能含帳號、私訊或付款資訊；不要把截圖權當成「只讀網頁文字」。[官方：captureVisibleTab](https://developer.chrome.com/docs/extensions/reference/api/tabs#method-captureVisibleTab)                                                                                              |

## 不屬於一般代理流程、但影響更大的權限

| 權限                                                                 | 能力                                                                                               | 風險判斷                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `"debugger"`                                                         | 用 Chrome DevTools Protocol 附著分頁，可觀察網路、偵錯 JS，並變更 DOM／CSS。                       | 幾乎是分頁的深度控制面；Chrome 不允許把它列為 optional permission，應避免放進一般網頁代理。[官方：debugger](https://developer.chrome.com/docs/extensions/reference/api/debugger)｜[官方：optional permissions 的例外](https://developer.chrome.com/docs/extensions/reference/api/permissions)                                                                                                                                                                |

| `"declarativeNetRequest"` 或 `"declarativeNetRequestWithHostAccess"` | 以規則封鎖、重新導向或修改網路請求／標頭。前者有安裝警告；後者須先取得 host permissions。          | 可改變網站如何載入與傳送資料；適合明確的網路規則產品，非一般操作頁面所需。[官方：declarativeNetRequest](https://developer.chrome.com/docs/extensions/reference/api/declarativeNetRequest)                                                                                                                                                                                                                                                                    |
| `"cookies"` + 對應 host permissions                                  | 查詢、設定與刪除指定網站 Cookie。                                                                  | 可能改變登入／工作階段狀態；只對必要網域、明確功能申請。[官方：cookies](https://developer.chrome.com/docs/extensions/reference/api/cookies)                                                                                                                                                                                                                                                                                                                  |
| `"proxy"`、`"privacy"`、`"contentSettings"`                          | 分別管理代理伺服器、隱私設定、各網站的 Cookie／JavaScript 等內容設定。                             | 影響整個瀏覽體驗或站點安全設定，屬高風險設定變更；`proxy` 不能列為 optional permission。[官方：proxy](https://developer.chrome.com/docs/extensions/reference/api/proxy)｜[官方：privacy](https://developer.chrome.com/docs/extensions/reference/api/privacy)｜[官方：contentSettings](https://developer.chrome.com/docs/extensions/reference/api/contentSettings)                                                                                            |
| `"browsingData"`、`"history"`、`"bookmarks"`、`"management"`         | 清除瀏覽器資料、增刪紀錄、管理書籤、管理已安裝的 app／擴充功能。                                   | 是帳戶與資料層級的變更，不是「點按網頁」的必要權限；清除資料尤應在動作前取得明確確認。[官方：browsingData](https://developer.chrome.com/docs/extensions/reference/api/browsingData)｜[官方：history](https://developer.chrome.com/docs/extensions/reference/api/history)｜[官方：bookmarks](https://developer.chrome.com/docs/extensions/reference/api/bookmarks)｜[官方：management](https://developer.chrome.com/docs/extensions/reference/api/management) |

## 對 Arlo 類型產品的最小權限建議

1. 一次性目前頁面操作：`["activeTab", "scripting", "sidePanel"]`；不要為了分頁導覽而加入 `"tabs"`。
2. 若 agent 開啟的分頁必須歸入 Arlo 群組，再加入 `"tabGroups"`；建立分頁本身不需要廣泛的 `"tabs"` 權限。
3. 需要跨導覽或在使用者選定網站持續工作時，將 `http://*/*`、`https://*/*` 放在 `optional_host_permissions`，在說明用途後由使用者主動授予實際網域。
4. 將 `debugger`、網路攔截、Cookie、代理設定與清除瀏覽資料排除在預設流程外；若未來加入，應是獨立、可理解、具明確確認的功能。
5. Chrome 的授權只限制「可碰觸的 API／網站範圍」，不會替頁面內的付款、送出、刪除做逐動作同意；產品仍應在這些不可逆步驟前暫停確認。

檔案與無痕模式也不是 host permission 自動涵蓋的範圍：使用者必須在擴充功能詳情頁另行開啟。[官方：Allow access to file URLs and incognito pages](https://developer.chrome.com/docs/extensions/develop/concepts/declare-permissions#allow-access)
