Ask Arlo…Stop

Built to stay out of your way

A small, focused assistant that works on the page you’re on.

Reads the tab you’re on

Ask about the page in front of you. Arlo reads it at the level of detail the task needs — compact, detailed, or raw HTML.

Lives in the side panel

No new tab, no context switch. Arlo sits next to the page and streams its answer as it works.

Opens tabs, keeps them tidy

Every tab Arlo opens goes into an “Arlo” tab group, so you can see them all and close them in one click.

Stop any time

One click halts a running task. You always see what Arlo is doing while it does it.

Bring your own model

Point Arlo at any OpenAI-compatible endpoint — OpenAI, Anthropic, a proxy, or a local model server. Keep several profiles.

Permissions on your terms

Nothing is granted at install. Site access is requested per origin, only when needed, and you can revoke it in Chrome.

Up and running in a minute

There’s no server to start — an endpoint and a key are the whole setup.

  1. Install and open the panel

    Click the Arlo toolbar icon to open the side panel.

  2. Add a model profile

    In the options page, enter an OpenAI-compatible endpoint and your API key. Choose whether the key is remembered or kept for the browser session only.

  3. Grant access when asked

    Chrome asks for access to your model’s site, and only if you choose, to all pages. Both are optional and revocable.

  4. Give it a task

    Describe what you want. Watch Arlo work, and stop it whenever you like.

Private by design

Arlo has no backend of its own, so there is nothing for us to collect.

  • No backend, no analytics, no tracking. The extension never contacts a server we run.
  • Keys and settings stay in your browser. Stored in Chrome’s extension storage on your device.
  • Page content goes only to your model endpoint. And only when you run a task.
  • Open source. Read exactly what it does on GitHub.
