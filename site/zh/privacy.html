隱私權政策

Arlo for Chrome · 最後更新：2026 年 10 月 1 日

摘要

Arlo 沒有後端、沒有分析追蹤。我們不會收集、儲存、販售或分享你的任何資料。你的設定與 API 金鑰留在你的瀏覽器中。頁面內容只會在你執行任務時，送往你自己設定的模型端點。

Arlo 會處理哪些資料

  • 模型設定檔與偏好設定——端點網址、模型名稱與主題，儲存在你裝置上的 Chrome 擴充功能儲存空間。
  • API 金鑰——每個設定檔可選擇由 Arlo 記住金鑰（存於本機擴充功能儲存空間），或只在目前瀏覽器工作階段中保留（關閉瀏覽器即清除）。金鑰只會送往它所屬設定檔的端點。
  • 網站內容——當你交辦需要讀取頁面的任務時，Arlo 會讀取你正在檢視的分頁文字。Arlo 只在你要求時才讀取頁面。內容連同你的提示會送往你設定的模型端點以產生回覆。
  • 分頁資訊——為了開啟分頁並歸入「Arlo」群組，Arlo 會建立分頁與分頁群組。Arlo 不會保存你的瀏覽紀錄。

Arlo 不會做的事

  • 沒有開發者營運的伺服器——Arlo 從不把資料傳給我們。
  • 沒有任何形式的分析、遙測、廣告或追蹤。
  • 不販售或轉讓使用者資料給第三方，唯一例外是把你的任務送到你自己選擇的模型端點。
  • 不將資料用於與 Arlo 單一用途無關的目的，也不用於信用評估或放貸。
  • 沒有遠端程式碼——Arlo 執行的一切都包含在擴充功能內。

你的模型供應商

你設定的端點（例如 OpenAI、Anthropic、代理伺服器或本機伺服器）會收到你的提示，以及 Arlo 一併送出的頁面內容。該供應商如何處理這些資料，由其自身的隱私權政策與條款規範。若希望一切都留在你的電腦上，請將 Arlo 指向本機模型伺服器。

權限

權限Arlo 為何需要
activeTab在你點擊工具列圖示後，讀取你開啟 Arlo 時所在的頁面。
scripting在目前分頁中執行頁面讀取器，以擷取其文字。
sidePanelArlo 的介面就是 Chrome 側邊欄。
storage在瀏覽器中儲存你的設定檔、API 金鑰與偏好設定。
tabGroups將 Arlo 開啟的每個分頁放進「Arlo」群組，方便你查看與關閉。
選用的網站存取安裝時不授予任何權限。Chrome 會詢問 (a) 你的模型端點來源，或 (b) 所有網頁（若你選擇讓 Arlo 不必點擊工具列就能讀取）。兩者都可隨時在 Chrome 撤銷。

你的掌控權

  • 隨時可一鍵停止執行中的任務。
  • 在選項頁刪除設定檔或金鑰。
  • 在 Chrome 的擴充功能詳細資料頁撤銷網站存取。
  • 解除安裝 Arlo 即可從瀏覽器移除它儲存的所有資料。

兒童

Arlo 是通用工具，並非針對 13 歲以下兒童設計。

政策變更

若本政策有變更，更新後的版本會連同新日期發布在此頁面。完整修改紀錄公開於程式碼倉庫。
