詢問 Arlo…停止

不打擾你的小幫手

小巧專注，只處理你正在看的頁面。

讀取你正在看的分頁

直接詢問眼前的頁面。Arlo 依任務需要選擇讀取的詳細程度——精簡、詳細或原始 HTML。

住在側邊欄

不必開新分頁、不必切換情境。Arlo 就在頁面旁邊，邊工作邊串流回覆。

開分頁，也幫你收好

Arlo 開啟的每個分頁都會放進「Arlo」分頁群組，一眼看清，一鍵關閉。

隨時可以停止

一鍵即可中止執行中的任務，Arlo 做事的過程你全程看得到。

自帶模型

指向任何相容 OpenAI 的端點——OpenAI、Anthropic、代理伺服器或本機模型伺服器，並可保存多組設定檔。

權限由你決定

安裝時不授予任何權限。網站存取只在需要時逐一詢問，並可隨時在 Chrome 撤銷。

一分鐘上手

不用啟動任何伺服器——一個端點加一把金鑰就完成設定。

  1. 安裝並開啟側邊欄

    點擊工具列的 Arlo 圖示即可開啟側邊欄。

  2. 新增模型設定檔

    在選項頁輸入相容 OpenAI 的端點與 API 金鑰，並選擇金鑰要長期記住，或只保留到瀏覽器工作階段結束。

  3. 依提示授予權限

    Chrome 會詢問是否允許存取你的模型網站；若你願意，也可以允許存取所有網頁。兩者皆為選用，且可隨時撤銷。

  4. 交辦任務

    描述你想做的事，看著 Arlo 工作，想停就停。

隱私優先的設計

Arlo 沒有自己的後端，所以我們沒有任何東西可以收集。

  • 沒有後端、沒有分析、沒有追蹤。擴充功能從不連線到我們營運的伺服器。
  • 金鑰與設定留在你的瀏覽器。儲存在裝置上的 Chrome 擴充功能儲存空間。
  • 頁面內容只會送到你的模型端點。而且只在你執行任務時。
  • 開放原始碼。在 GitHub 上查看它實際做了什麼。
